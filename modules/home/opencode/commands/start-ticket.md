Start by reading Linear issue $1 and its comments with
`linearis issues read $1 --with-comments`. Read its relations with
`linearis issues relations list $1`. Determine where implementation currently
stands; it is usually brand new, but check for existing commits, whether the
branch is pushed, any associated PR, and its review and check status.
Inspect the repository for the relevant implementation context.

When the current state is brand new this can go without saying,
If not describe what exists currently.

Next describe the issue and start working with me on a plan.
Usually the grill me skill is apropriate here.
