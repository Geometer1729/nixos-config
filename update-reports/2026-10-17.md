### Worth Reviewing

- **tmux 3.7 parser (INCOMPATIBLE upstream).** Configuration is now parsed by yacc, and a lone `\` must be quoted. The generated `tmux.conf` parses cleanly under a scratch 3.7b server (`source-file -n`, exit 0), and the multi-line `@restore-processes` value is identical. The running servers on durin and gimli are still **3.6a** until the next reboot or full tmux restart. The first 3.7b restore therefore happens at the next boot. Also from upstream: names may no longer contain `.`, `:`, or `#`; there are reports of Shift+Enter breaking inside tmux 3.7c (we have 3.7b) and of `list-keys -T` printing to the status line.
- **Claude Code 2.1.302** reverts the 2.1.283 change. `claude -p` and Agent SDK sessions without an explicit mode on third-party providers or with telemetry off start in `default` again, not `auto`. Meridian is affected; `modules/home/claude/default.nix` still sets no `permissions.defaultMode`. 2.1.302 also enables fork subagents by default in SDK sessions (`CLAUDE_CODE_FORK_SUBAGENT=0` disables), and 2.1.290 asks approval for more `ps` forms.
- **OpenCode 2.0.29+** automatically continues responses that hit the output-token limit, which can mean extra requests through the Meridian proxy. Rejected `execute.before` hooks now fail only the tool call (the LSP plugin's direnv failure path benefits). Configured model limits are seeded before transforms.
- **wpa_supplicant 2.12 on gimli** (wpa_supplicant module, not NetworkManager). The multi-config patch is kept, and the external-password handling needed by `pskRaw = "ext:…"` is upstream. Multicast filtering now applies to all networks. Upstream reports cover EAP-TLS 4-way handshakes and brcmfmac offload; neither applies to gimli's PSK network. Gimli stayed associated on 5220 MHz through activation.
- **systemd 260.5** carries upstream's fix for the lost `Reloading(false)` reexec signal, and nixpkgs dropped its temporary patch (`34dffea`). durin reexecuted cleanly at 10:18:10.
- **Browsers.** Chrome/Chromium 155 (247 security fixes in Ungoogled's 155 bump). Brave Origin's builder adds GPU/Vulkan/speech libraries, which should restore VA-API decoding and WebGPU.
- **glibc** still lacks the CVE-2026-95818 fix (`$ORIGIN`/`AT_SECURE`); don't treat this bump as closing it.
- **Podman 5.8.8 / Foundry:** after the reboot, the transient healthcheck failed once, as tracked, then cleared.
- **PrismLauncher develop:** the built-in `OSX`/`iOS` icon themes were removed (a persisted choice is rejected, not migrated) and `Flat` was renamed *Material*. There are toolbar changes, multi-select deletion for worlds/servers, and path-containment checks on pack imports.
