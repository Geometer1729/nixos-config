## Migration Review

### Action Required

- Linearis source `6e2973f` reports `2026.8.0`, while the mutable npm `next` tag had advanced to `2026.8.0-next.2`. The existing assertion correctly stopped evaluation. `linearis-npm` is now pinned to the exact `2026.8.0` metadata artifact; the assertion remains in place.
- Linearis removed `projects archive` in favor of `projects delete`, tightened milestone-name lookup to the selected project, and changed invalid CLI invocations to JSON errors on stderr with exit status 2. No tracked local script uses the removed command.

### Worth Reviewing

- PostgreSQL 18.6 introduces `output_plugin_libraries` restrictions and possible cleanup for GIN, `btree_gist`, and `ltree`. The local 18.4 cluster has no logical replication slots, GIN indexes, or affected extensions, so no migration is needed here.
- Firefox 154 prompts before public sites open WebSockets to local-network services. Local web UIs may require a one-time permission decision.
- Claude Code 2.1.232 enables subagent forking by default, and non-teammate interactive agents may background by default. Newer models hide Todo tools unless `CLAUDE_CODE_ENABLE_TODO_TOOLS=1`.
- Meridian 1.62.7 adds a daily npm update check. Set `MERIDIAN_NO_UPDATE_CHECK=1` if the Nix-managed service should not query npm.
- Tuigreet is a major jump. Existing `--time`, `--asterisks`, `--user-menu`, and `--cmd` flags remain supported, but login should be smoke-tested after reboot.
- Discord gains NVENC/Vulkan wrapper paths; screen sharing and hardware encoding should be tested.

### No Action Needed

- Home Manager, Nixvim, Stylix, sops-nix, git-hooks, and the consumed NUR module/package surfaces have no relevant option removals or migrations.
- OpenSSH 10.5's ECC requirement is satisfied by the standard nixpkgs crypto build. No unusual crypto override is configured.
- The configured OpenCode model `openai/gpt-5.6-sol` exists with unchanged metadata in both old and new model catalogs.
