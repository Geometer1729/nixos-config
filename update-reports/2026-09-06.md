## Migration Review

### Action Required

- No declarative configuration migration is required.
- No reboot is required for a kernel change; all hosts remain on Linux 6.18.49. Torag was nevertheless rebooted to recover its graphical session after live activation.

### Worth Reviewing

- Nix 2.35.2 changes the store schema. During the first `nh os test`, stale pre-upgrade `nixd` evaluator workers held old store connections and deadlocked the schema transition. Terminating only those evaluator workers released the lock; Home Manager activation and a repeated `nh os test` then passed. This is a one-time live-upgrade hazard rather than a configuration migration.
- ncspot 1.4.0 and rsync 3.5.0 are feature releases. Their installed command names and local configuration surfaces remain valid, but normal-use smoke testing is appropriate.
- Claude Code and OpenCode are patch updates. Their package expressions and consumed configuration interfaces remain compatible.
- Live NixOS switches restart Home Manager and can close terminals, crash/restart Waybar, and disturb the active Hyprland workspace. Use tmux and prefer a planned reboot for interactive GUI hosts.

### No Action Needed

- Home Manager and Nixvim changed only upstream lock metadata; no consumed module implementation changed.
- `nix-index-database` remains unused; stock Home Manager nix-index is active instead.
- The direct `firefox-addons` package list remains empty; configured extensions are installed through Firefox policy URLs.
- NUR changed only `repos.json`, registry locks, and flake locks. No NUR module or output implementation changed. Stylix's indirectly consumed `rycee.firefox-addons.firefox-color` remains version 2.1.7 with identical metadata and the identical output path.
- NUR removed repository `thestaccato`, but this configuration has no `nur.repos.thestaccato` or other direct `nur.repos.*` reference.
