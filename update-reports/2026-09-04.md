## Migration Review

### Action Required

- Reboot all hosts to run Linux 6.18.49; the deployed generation is active but the running kernel remains the pre-update kernel until reboot.

### Worth Reviewing

- Firefox 155 changes captive-portal checks from `detectportal.firefox.com` to `firefox-portal-detection.com`. No local allowlist names the old host, but restrictive external networks may need it allowed. Firefox 155 also has a known issue on networks that block UDP/QUIC; disabling `network.http.happy_eyeballs_enabled` is the temporary upstream workaround.
- Claude Code 2.1.241 -> 2.1.261 changes model defaults and prompt editing, adds `/diff` and output-size settings, and adjusts read/Bash permission behavior. The Home Manager option surface is unchanged.
- GitHub CLI 2.99 adds repeatable `--attach` support and `gh issue develop --worktree`, and fixes linked-worktree branch handling.
- Brave moves to the Chromium 152 line. Its package override interface and binary name are unchanged, but profile/session automation should be smoke-tested.
- PrismLauncher removes MCEdit integration and changes memory reporting, managed-pack Java reset behavior, dependency handling, and several mod/UI workflows. No tracked config uses MCEdit.
- `nix flake check` now warns that installer `boot.zfs.forceImportRoot` defaults to `true` and will default to `false` in 26.11. This does not affect the current hosts, but should be made explicit before the next release migration.

### No Action Needed

- Flake-parts, git-hooks, Nixvim, NUR, sops-nix, and the configured module surfaces have no relevant breaking changes.
- `nix-index-database` remains unused; stock Home Manager nix-index is active instead.
- The Syncthing `ignorePatterns` escaping fix is safe and the config does not currently define that option.
- The Firefox wrapper's new `appDataDir` argument is additive and unused locally.
