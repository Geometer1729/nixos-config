## OpenCode cli.json Incident (durin)

At 11:33:01, twenty minutes after `just switch`, an OpenCode 2.3.0 process replaced the Home Manager symlink `~/.config/opencode/cli.json` with a 272-byte file that kept only theme/diffs/session keys and `session.permissions = "autoaccept"`. It dropped `plugins`, `tabs`, `attention`, `session.markdown` and `theme.mode`. The notifications TUI plugin then loaded only through the server's plugin list, without options, so `focusCommand` was undefined and mako clicks did nothing (`plugins/notifications/tui.ts:38`); vim, auto-tabs and dictation unloaded too.

Diagnosis: `notify.sh --focus` → server presence socket → TUI → `opencode-focus` → `hyprctl`. A fake TUI client on the socket received the forwarded session ID (server side fine); `strace` on a real TUI showed it received the message but never exec'd `opencode-focus`. Fix: restored the generated `cli.json` (keeping `autoaccept`); the TUIs reconciled 19 plugins instead of 16, and a replayed click exec'd `opencode-focus` → `tmux select-pane` → `hyprctl dispatch` focus. An earlier rewrite at 10:35 (HM's `cli.json.bkp`) had kept the keys, so which writer drops them is unproven; the running OpenCode is still 2.3.0 with plugins built for 2.4.1. Task 43.
